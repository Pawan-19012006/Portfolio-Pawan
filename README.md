# Pawan Eswaran — Engineering Portfolio

A cinematic, editorial-style engineering portfolio crafted to showcase software development expertise through immersive interactions, fluid motion, and modern minimalist design.

Built as a fully custom Single Page Application using React, Vite, Tailwind CSS, and Framer Motion.

---

## Overview

This portfolio is designed as a high-performance interactive experience rather than a traditional personal website.

The application combines:

- Editorial-inspired layouts
- Hardware-accelerated motion design
- Snap-scroll storytelling
- Glassmorphic UI systems
- Route-based transition choreography
- Responsive immersive navigation

Every interaction is intentionally designed to feel tactile, cinematic, and premium.

A bold split-screen hero layout featuring synchronized kinetic typography and responsive motion choreography.

### Highlights

- 50/50 responsive editorial composition
- Large-format typography using Plus Jakarta Sans
- Animated text sequencing
- Motion-driven interaction layers
- Minimal high-contrast visual hierarchy

## Horizontal Project Showcase

A fully custom horizontal scrolling system engineered with snap-scroll behavior and animated 3D perspective transitions.

### Highlights

- Horizontal snap-scrolling
- CSS perspective card flips
- Dynamic project metadata

- Responsive immersive transitions

# Installation

## Prerequisites

Ensure the following are installed:

- Node.js `v18+`
- npm

---

## Clone Repository

```bash
git clone https://github.com/Pawan-19012006/Portfolio-Pawan.git

cd Portfolio-Pawan
```

---

## Install Dependencies

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

Visit:

```bash
http://localhost:5173
```

# Design Philosophy

## Typography First

Large-scale typography is used as the primary navigational and emotional design element.

---

## Editorial White Space

Generous spacing and asymmetrical layouts create a premium reading flow and immersive visual rhythm.

---

## Motion as Interaction

Animations are designed around tactile responsiveness:

- Magnetic hover interactions
- Perspective transitions
- Blur/fade choreography
- Spring-based motion systems
- Scroll-triggered viewport reveals

---

## High-Contrast Dark UI

The interface is built around a minimalist dark palette for maximum readability and cinematic presentation.

```css
#0a0a0a
#f4f4f4
```
